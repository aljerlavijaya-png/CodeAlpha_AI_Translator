# AI Language Translator

## About the Project

This project was developed as part of my **CodeAlpha Internship**. It is a simple and responsive AI Language Translator that allows users to translate text from one language to another using the Google Translate API.

The main goal of this project is to provide a clean and easy-to-use interface where users can quickly translate text between different languages.

---

## Features

- Translate text into multiple languages
- Select source and target languages
- Swap languages with one click
- Copy translated text
- Listen to translated text using Text-to-Speech
- Responsive design for mobile and desktop
- Simple and user-friendly interface

---

## How to Run

1. Clone or download this repository.
2. Open the project in Visual Studio Code.
3. Install the required Python packages:
   pip install -r requirements.txt
4. Run the application:
   python app.py
5. Open your browser and visit:
   http://127.0.0.1:5000
